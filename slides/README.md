# Laminas de presentacion

Cinco tipos de lamina, disenados a 1920×1080 y escalados a 1280×720 para la vista de tarjeta.
Son la aplicacion de la seccion *De la pantalla a la lamina* del sistema:

- **Portada** y **Separador** sobre azul Vikua #001332, logotipo a tinta blanca arriba a la izquierda,
  titulo en Poppins 600 y no mas de dos lineas.
- **Cifras**, **Datos**: fondo blanco, maximo tres bloques, cada cifra con una linea de color superior.
- Texto nunca por debajo de 24 pt a 1920×1080 (en estos archivos, 24 px reales).
- El fondo corporativo se reserva para portadas, separadores y cierre.

Las plantillas no llevan iconografia decorativa: el color estructura y la cifra manda.
