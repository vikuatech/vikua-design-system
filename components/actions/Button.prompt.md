Boton de accion del sistema. Usa `primary` una sola vez por vista.

```jsx
<Button variant="primary">Crear analisis</Button>
<Button variant="outline" size="sm" icon={<Icon name="sliders" size={16} />}>Filtros</Button>
<Button variant="primary" uppercase>Buscar</Button>
```

Variantes: primary (naranja de accion), secondary (azul Vikua #001332), outline, text (enlace en azul info), destructive.
Tamanos 32 / 40 / 48. `uppercase` solo para BUSCAR en la barra de busqueda global.
