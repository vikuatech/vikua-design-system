Accion de un solo icono; siempre con `label`.

```jsx
<IconButton label="Notificaciones" shape="circle"><Icon name="bell" size={18} /></IconButton>
<IconButton label="Mas opciones" variant="ghost"><Icon name="more-horizontal" size={18} /></IconButton>
```

`variant="onBrand"` para colocarlo sobre el azul #001332.
