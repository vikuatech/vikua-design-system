Usa `Icon` para cualquier icono del sistema: envuelve Feather Icons, el set oficial de Vikua.

```jsx
<Icon name="map-pin" size={20} color="var(--vk-accent)" />
```

La pagina debe cargar Feather una vez: `<script src="https://unpkg.com/feather-icons@4.29.2/dist/feather.min.js"></script>`.
Nombres usados en producto: `grid`, `bar-chart-2`, `map`, `database`, `users`, `briefcase`, `trending-up`, `log-out`, `heart`, `bell`, `help-circle`, `search`, `sliders`, `chevron-right`, `plus`.
Nunca dibujes un SVG a mano ni uses emoji como icono.
